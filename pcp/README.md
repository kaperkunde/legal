# PCP — Legal

Legal documentation for **PCP**, the self-hosted gateway to your MCP servers, published by
Kaperkunde as open-source software at
[github.com/kaperkunde/pcp](https://github.com/kaperkunde/pcp).

**Effective date: 6 October 2026** · [Repository overview](../README.md)

---

## Documents

| Document | Description |
|----------|-------------|
| [Terms of Use](terms.md) | Open source under the MIT licence, offered as it is: whoever runs an instance is its operator and runs it at their own risk |
| [Privacy Notice](privacy.md) | Kaperkunde holds nothing through PCP; what an instance keeps on its own machine, and that the operator is answerable for it |
| [Licence](https://github.com/kaperkunde/pcp/blob/main/LICENSE) | The MIT licence the code is published under |
| [Privacy Policy](../privacy.md) | The company-wide policy, which covers Kaperkunde's own websites and services and what you send Kaperkunde yourself, not an instance somebody runs |

PCP is free and open source. There is **no account, no service and no acceptance gate**: the MIT
licence is what you accept by using the code, and these documents say what that means for
whoever runs it.

There is **no subprocessor list**, because Kaperkunde processes nothing for PCP. The servers and
the assistant an operator connects are their own relationships, as the
[Privacy Notice](privacy.md#where-it-goes) says.

## How these are published

PCP does not carry this repository as a git submodule. Its footer links to this folder on the
`main` branch of this repository, so a change here is published the moment it lands on `main`.
