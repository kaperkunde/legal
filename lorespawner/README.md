## How these are published

Lore Spawner renders these files directly. The app carries this repository as a git submodule at
`legal/` and builds the markdown into its pages, so `/legal`, `/legal/subprocessors` and
`/terms` on the site are this folder, and `/legal/kaperkunde` is the company-wide policy beside
it. Changing a document here and bumping the submodule is what publishes it.
